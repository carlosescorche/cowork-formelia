# Log de decisiones del CEO

Registro inmutable de decisiones estratégicas. Una decisión por archivo, nombrada
`AAAA-MM-DD-slug.md`, usando [TEMPLATE.md](TEMPLATE.md).

## Reglas

1. **Se registra todo lo que un CEO decide:** pricing, posicionamiento, canales, contrataciones,
   pivotes, inversiones de tiempo/dinero, qué NO hacer.
2. **Las decisiones no se editan.** Si el contexto cambia, se escribe una decisión nueva que
   indica a cuál supersede.
3. **Toda decisión enlaza sus consecuencias:** qué documento de estrategia cambia a raíz de ella.
4. Al registrar una decisión, añadirla a la lista de abajo y a
   [`memoria.md`](../memoria.md).

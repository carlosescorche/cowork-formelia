# Entrevistas a usuarios

El instrumento #1 de la fase pre-PMF. Target Q3-2026: **20+ entrevistas**.

## Estructura

```
entrevistas/
├── guion-v1.md         Guion vivo de entrevista (por crear — prioridad agosto)
├── 2026-09-01-nombre-segmento.md    Una entrevista por archivo
└── sintesis/           Síntesis mensuales de patrones: AAAA-MM.md
```

## Formato de cada entrevista

Frontmatter: fecha, nombre (o seudónimo), segmento (agencia/educación/salud/servicios/eventos/
RRHH), país, plan, cómo nos encontró. Cuerpo: notas crudas + **3 highlights** (citas textuales)
+ acción sugerida (si la hay).

## Guion base (esqueleto para `guion-v1.md`)

1. **Su flujo hoy:** ¿cómo capturas información de clientes/alumnos/pacientes hoy? (dejar que
   describa el combo Forms+WhatsApp+Sheets sin sugerirlo)
2. **El dolor:** ¿qué es lo más tedioso? ¿qué se te ha perdido o roto?
3. **Historia:** ¿qué probaste antes? ¿por qué lo dejaste? ¿qué pagas hoy por herramientas?
4. **Con Formelia** (si ya la usó): ¿qué esperabas? ¿qué pasó? ¿dónde te atascaste? ¿a quién se
   la recomendarías con sus palabras?
5. **Sean Ellis** (usuarios activos): ¿cómo te sentirías si no pudieras usarla más?

## Reglas

1. Escuchar 80 / hablar 20. Nunca vender durante la entrevista.
2. Pedir permiso para citar. Anonimizar por defecto en documentos públicos.
3. Máximo 48h entre entrevista y notas escritas (la memoria miente).
4. Cada 5 entrevistas → síntesis de patrones en `sintesis/`. Un patrón repetido 3+ veces →
   hallazgo accionable → avisar al área dueña.

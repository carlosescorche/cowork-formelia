# X (Twitter) — @formelia + founder

**Rol:** build in public para la comunidad maker/startup hispana, early adopters e inversores
futuros. Aquí se construye la narrativa de "founder técnico serio con velocidad demostrada".

## Qué transmitimos

Honestidad radical con datos: métricas reales (buenas y malas), decisiones de producto y de
empresa, el porqué de las apuestas (español nativo, sin sparkles, evals antes que demos).

## Cadencia y formatos

- **4–5 tuits/semana** desde el perfil del founder:
  - 1 hilo semanal (lunes): progreso, métricas, aprendizaje de la semana.
  - 2–3 tuits sueltos: capturas de producto, micro-decisiones, observaciones del mercado
    hispano de SaaS.
  - Reciclar lo mejor de LinkedIn adaptando el registro (más directo, más corto).
- La cuenta de marca @formelia: anuncios, replies de soporte, retuits del founder.

## Reglas

- Números reales o nada. "Mes 1: 300 registros, 41% activación" > "¡Gran mes!".
- No participar en guerras de opiniones de IA; nuestra postura se muestra con el producto.
- Español por defecto; inglés solo si el contenido es específicamente para audiencia global
  (poco frecuente — el foco es el mercado hispano).
- Documentar los hilos importantes aquí ANTES de publicar (sirven de memoria y se reciclan a
  blog).

## Almacenamiento de piezas

Convención: `AAAA-MM-DD-slug.md` con el hilo/tuit completo y, publicado, el link.

```
x-twitter/
└── 2026-08-04-hilo-11-dias-para-lanzar.md
```

## Métricas que importan

Respuestas y QTs de perfiles del nicho · seguidores maker/inversor · tráfico con
`utm_source=x` · DMs de calidad (potenciales partners, prensa, inversores).

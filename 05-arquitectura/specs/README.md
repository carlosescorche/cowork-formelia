# Specs y ADRs

- **Specs de feature:** `AAAA-MM-DD-slug-spec.md` — traducen un PRD de
  [`04-producto/prds/`](../../04-producto/prds/README.md) a diseño técnico: modelo de datos,
  APIs, caché, RLS, diagramas (Mermaid), plan de rollout.
- **ADRs:** `adr-NNN-slug.md` — decisión, contexto, alternativas descartadas, consecuencias.
  No se editan después: una decisión nueva supersede la anterior.

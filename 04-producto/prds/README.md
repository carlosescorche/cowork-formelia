# PRDs

Un archivo por PRD: `AAAA-MM-DD-slug.md`.

Estructura mínima: problema y persona → propuesta → alcance (in/out) → métrica de éxito →
riesgos → estado (💡 borrador · ✅ aprobado · 🏗️ en construcción · 🚢 lanzado).

Un PRD aprobado pasa a especificación técnica en [`05-arquitectura/`](../../05-arquitectura/).
